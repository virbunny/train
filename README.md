## 部署方式

請將 ZIP 內全部檔案放在同一層：

- index.html
- manifest.webmanifest
- service-worker.js
- tourist-train-rabbit-icon-v69-180.png
- tourist-train-rabbit-icon-v69-192.png
- tourist-train-rabbit-icon-v69-512.png

不要只更新 index.html，否則 PWA 快取與桌面圖示可能仍使用舊版。
