## 部署方式

請把 ZIP 內所有檔案放在同一層：

- index.html
- manifest.webmanifest
- service-worker.js
- tourist-train-rabbit-icon-v67-180.png
- tourist-train-rabbit-icon-v67-192.png
- tourist-train-rabbit-icon-v67-512.png
- 日本觀光列車_旅印帖_週報交接_v67.md

不要只替換 index.html，否則 PWA 快取與桌面圖示可能不會更新。
